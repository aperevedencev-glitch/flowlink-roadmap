# Разнесение выписки — Московская областная нотариальная палата

Приложение разносит банковскую выписку палаты:

- **поступления** — по нотариусам и статьям доходов (членские и целевые взносы, проценты банка, возмещения, возвраты, прочее);
- **списания** — по статьям расходов (оплата труда, ЕНП, отчисления в ФНП, аренда, коммунальные услуги, связь, ПО, обучение, командировки, банковские комиссии и т. д.);
- готовит **Excel для загрузки в 1С**: листы «Поступления», «Списания», «Свод по статьям» со статьёй, счётом учёта, нотариусом и периодом.

## Как открыть

- **Автономная версия (GitHub Pages):** https://aperevedencev-glitch.github.io/flowlink-roadmap/monp/ (если для репозитория включены GitHub Pages) — разбор выписки и выгрузка в Excel работают прямо в браузере; файлы никуда не отправляются. Справочник нотариусов — базовый список с сайта палаты (`notaries.json`).
- **Рабочая версия в claude.ai** — с общим хранилищем: справочник нотариусов с ИНН и взносами, запоминание контрагентов, журнал проведённых операций, отчёт по взносам нотариусов.

## Какие файлы принимает

- файл обмена 1С из банк-клиента `kl_to_1c.txt` (1CClientBankExchange, UTF-8 или Windows-1251);
- выписку из интернет-банка в Excel (`.xlsx`) или CSV со столбцами «Дата», «Дебет»/«Кредит» (или «Сумма»), «Контрагент», «ИНН», «Назначение платежа»;
- строки, скопированные из Excel вместе с заголовком.

## Как робот разносит

| Что | Признаки, по убыванию надёжности |
| --- | --- |
| Нотариус | ИНН плательщика → запомненный плательщик → ФИО плательщика или «нотариус Фамилия И.О.» в назначении |
| Статья | запомненный контрагент → ключевые слова из справочника статей → «Членские взносы» для платежа нотариуса без пометок → статья по умолчанию |
| Период | месяц, квартал или год из назначения платежа |

Статусы строк: «Авто» (уверенность от 85 %), «Проверить» (50–84 %), «Не определено», «Вручную», «Уже разнесено».

## Файлы

- `index.html` — приложение целиком (HTML + CSS + JS, библиотека JSZip с cdnjs);
- `notaries.json` — 389 нотариусов (ФИО и город конторы) со страницы [«Список нотариусов»](https://monp.ru/list-notaries/) на 15.11.2026; ИНН и размеров взносов в открытом доступе нет.

Счета учёта в справочнике статей предложены по типовому плану счетов НКО и подлежат проверке по учётной политике палаты.
