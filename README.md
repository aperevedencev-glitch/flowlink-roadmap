# Flowlink: дорожная карта

Дорожная карта робота Flowlink: этапы от выгрузки договоров из ЕИС до передачи в НОСТРОЙ, изменения и их причины, журнал ошибок и оставшиеся шаги.

Откройте `index.html` в браузере. Страница самодостаточна, изображение встроено в файл.
